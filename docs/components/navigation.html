Navigation Component

Horizontal/vertical navigation, dropdowns, breadcrumbs, and responsive mobile menus

Overview

The Navigation component provides comprehensive navigation solutions for websites and applications. It includes horizontal and vertical navigation, multi-level dropdowns, breadcrumbs, filter navigation, and responsive mobile menus. The component maintains the original A.mphibio.us design patterns while adding modern accessibility features and responsive behavior.

Multiple Layouts

Horizontal, vertical, and modern navigation layouts with full aiab-dropdown support.

Responsive Design

Automatic mobile adaptation with hamburger menus and touch-friendly interactions.

Dropdown Menus

Multi-level dropdowns with hover and click interactions for complex navigation structures.

Breadcrumb Navigation

Multiple aiab-breadcrumb styles with customizable separators for hierarchy display.

Full Accessibility

Keyboard navigation, focus management, ARIA attributes, and screen reader support.

Flexible Styling

CSS variables for easy theming, transparent navigation, and sticky positioning.

JavaScript API

Navigation is markup-first: the site nav is enhanced automatically when the framework loads. Use amp.createNavigation() for any other nav, or to change options. It enhances your markup; it doesn't render any.

Live: amp.createNavigation('#api-demo-nav', …)
  • Docs
  • Navigation
    • Options
    • Methods
  • Examples

isOpen: false

"Navigation" is highlighted because currentPath matches it. Below 768px the toggle opens this list as the mobile menu; Escape or a click outside closes it.

const nav = amp.createNavigation('#api-demo-nav', {
  toggle: '#api-demo-toggle',          // button outside the nav
  currentPath: '/docs/components/navigation.html',
  onToggle: (isOpen) => {
    status.textContent = `isOpen: ${isOpen}`;
  }
});

nav.open();      // nav.close() · nav.toggle() · nav.isOpen
nav.destroy();   // removes every listener

Options

OptionDefaultWhat it does
breakpoint768Width (px) at or below which the mobile menu and tap-to-expand dropdowns apply
stickytrue for .aiab-site-navAdds .is-scrolled after the page header scrolls away
highlightCurrenttrueMarks the current page with .aiab-active + aria-current="page" (hash-only links never count)
currentPathlocation.pathnamePath to match instead of the real URL
toggleautoMenu button: one inside the nav, else one whose aria-controls points into it
onTogglenone(isOpen) => void after the menu opens or closes

Methods

open(), close(), toggle(), setActiveStates(), destroy(); read-only isOpen and element. Calling createNavigation again on the same element replaces the previous instance, so handlers never double up.

JavaScript Integration

You don't need to write toggle or dropdown code: the built-in Navigation handles the mobile menu, tap-to-expand dropdowns, arrow-key movement, focus trapping, Escape and outside clicks (see JavaScript API). Hook into it instead:

// React to the menu opening (analytics, locking scroll, etc.)
amp.createNavigation('.aiab-site-nav', {
  onToggle: (isOpen) => document.body.classList.toggle('menu-open', isOpen)
});

// After a client-side route change, re-run current-page highlighting
window.amphibiousNav?.setActiveStates();

// Module usage
import { Navigation } from '@agency-in-a-box/amphibious';
const nav = Navigation.getInstance(document.querySelector('.aiab-site-nav'));
nav?.close();

Best Practices

Structure Guidelines

  • Semantic markup: Use <nav> elements and proper list structures for screen readers
  • Clear hierarchy: Structure navigation items logically with appropriate nesting levels
  • Consistent labeling: Use descriptive link text and maintain consistent naming patterns
  • Current page indication: Always mark the current page/section with active states

Responsive Design

  • Mobile first: Design for mobile devices first, then enhance for larger screens
  • Touch targets: Ensure navigation links are at least 44px for touch devices
  • Hamburger menus: Use clear icons and labels for mobile menu toggles
  • Progressive enhancement: Ensure navigation works without JavaScript

Accessibility

  • Keyboard navigation: Support Tab, Enter, Escape, and arrow keys for navigation
  • Focus management: Provide clear focus indicators and logical tab order
  • ARIA attributes: Use aria-expanded, aria-current, and aria-label appropriately
  • Skip links: Provide skip navigation links for screen reader users

Performance

  • Minimal JavaScript: Use CSS for hover effects and basic interactions
  • Lazy loading: Load aiab-dropdown content only when needed for large menus
  • Optimize images: Use SVG icons and optimize any logo images
  • CSS efficiency: Use CSS variables for easy theming and maintenance
