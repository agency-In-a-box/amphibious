Grid System v2.0.0

Amphibious uses a 16-column responsive aiab-grid system based on flexbox.

Container Classes

.aiab-container

Fixed-width aiab-container with responsive breakpoints (max-width: 960px)

.aiab-container-fluid

Full-width aiab-container that spans the entire viewport width

Grid Classes

.aiab-row

Creates a horizontal group of columns with negative margins

.col-{1-16}

Column width for desktop screens (e.g., .aiab-col-8 = 50% width)

.col-tablet-{1-16}

Column width for tablet screens (≤768px)

.col-mobile-{1-16}

Column width for mobile screens (≤480px)

Example Usage

<div class="aiab-container">
  <div class="aiab-row">
    <div class="aiab-col-8 aiab-col-tablet-16 aiab-col-mobile-16">
      Main content (50% on desktop, full width on tablet/mobile)
    </div>
    <div class="aiab-col-8 aiab-col-tablet-16 aiab-col-mobile-16">
      Sidebar (50% on desktop, full width on tablet/mobile)
    </div>
  </div>
</div>

Navigation API

Navigation is markup-first. The site nav (.aiab-site-nav) is enhanced automatically when the framework loads: mobile menu, dropdowns, keyboard support and current-page highlighting. Call the API only for other navs on the page, or to change options.

createNavigation()

amp.createNavigation(element?: string | HTMLElement, options?: NavigationOptions): Navigation

Enhances existing navigation markup and returns the instance. If the element already has an instance (for example the auto-initialised site nav), that instance is destroyed first, so the new options apply and event handlers never double up. Same as Navigation.create() when importing the module.

Parameters

Parameter Type Required Description
element string | HTMLElement No Root element or selector. Omitted: the site nav. Throws if a selector matches nothing.
options NavigationOptions No See below.

NavigationOptions

Property Type Default Description
breakpoint number 768 Viewport width (px) at or below which the mobile menu and tap-to-expand dropdowns apply. Matches --bp-md-down.
sticky boolean true for .aiab-site-nav Adds .is-scrolled once the page scrolls past .aiab-docs-header / .aiab-hero.
highlightCurrent boolean true Marks the link for the current page with .aiab-active and aria-current="page". Hash-only links never count.
currentPath string location.pathname Path to match instead of the real URL (useful for demos and tests).
toggle string | HTMLElement auto Menu toggle button. By default: a toggle inside the nav, else a button whose aria-controls points into it.
onToggle function undefined (isOpen: boolean) => void, called after the mobile menu opens or closes.

Search and the theme toggle are separate components (SearchBar, DarkModeToggle). Navigation doesn't render markup.

Returns: Navigation, the navigation instance

Example Usage

// A second nav on the page, collapsing at 960px
const docsNav = amp.createNavigation('#docs-nav', {
  breakpoint: 960,
  sticky: false,
  onToggle: (isOpen) => {
    console.log('Mobile menu is', isOpen ? 'open' : 'closed');
  }
});

// Reconfigure the auto-initialised site nav
amp.createNavigation('.aiab-site-nav', { breakpoint: 1024 });

// As a module
import { Navigation } from '@agency-in-a-box/amphibious';
const nav = Navigation.create('#docs-nav', { highlightCurrent: false });

Navigation Methods

Method / property Description
open() · close() · toggle()Control the mobile menu.
isOpenWhether the mobile menu is open (read-only).
elementThe root element (read-only).
setActiveStates()Re-run current-page highlighting, for example after a client-side route change.
destroy()Remove every listener, close the menu and detach the instance.
Navigation.getInstance(el)The instance attached to an element, if any.

Example Usage

const nav = amp.createNavigation('#docs-nav');
nav.open();
// Later...
nav.destroy();

Modal API

createModal()

amp.createModal(id: string, selector: string | HTMLElement, options?: ModalOptions): AmphibiousModal

Creates a new aiab-modal dialog with customizable options and event handling.

Parameters

Parameter Type Required Description
id string Yes Unique identifier for the aiab-modal
selector string | HTMLElement Yes CSS selector or DOM element for the aiab-modal content
options ModalOptions No Configuration options for the aiab-modal

ModalOptions Interface

Property Type Default Description
size 'sm' | 'md' | 'lg' | 'xl' 'md' Modal size variant
centered boolean false Vertically center the aiab-modal
backdrop boolean true Show backdrop overlay
keyboard boolean true Close aiab-modal on Escape key
animation 'fade' | 'slide' | 'zoom' 'fade' Animation type for show/hide

Modal Methods

open()

modal.open(): Promise<void>

Opens the aiab-modal with animation.

close()

modal.close(): Promise<void>

Closes the aiab-modal with animation.

toggle()

modal.toggle(): Promise<void>

Toggles the aiab-modal open/closed state.

Example Usage

// Create a aiab-modal
const modal = amp.createModal('myModal', '#modalContent', {
  size: 'lg',
  centered: true,
  animation: 'fade'
});

// Open the aiab-modal
await modal.open();

// Close after 3 seconds
setTimeout(() => modal.close(), 3000);

Stats Pattern

Display key metrics and statistics in a clean, scannable format.

CSS Classes

.aiab-stats

Container for statistics list (use with <ul>)

.aiab-stats--large

Modifier for larger stat display

.aiab-stats--vertical

Modifier for vertical layout

.aiab-stat-value

The numerical value or main metric

.aiab-stat-label

Descriptive label for the statistic

Example Usage

<ul class="aiab-stats aiab-stats--large" aria-label="Website statistics">
  <li>
    <strong class="aiab-stat-value">1.2M+</strong>
    <span class="aiab-stat-label">Downloads</span>
  </li>
  <li>
    <strong class="aiab-stat-value">99.9%</strong>
    <span class="aiab-stat-label">Uptime</span>
  </li>
  <li>
    <strong class="aiab-stat-value">< 100ms</strong>
    <span class="aiab-stat-label">Response Time</span>
  </li>
</ul>

Slats Pattern

Display a list of items with consistent spacing and optional borders.

CSS Classes

.aiab-slats

Container for slats list (use with <ul>)

.aiab-slats--products

Modifier for product listings

.aiab-slats--testimonials

Modifier for testimonial content

.slat-item

Individual slat content wrapper

.slat-content

Main content area of a slat

.slat-actions

Action buttons area

Example Usage

<ul class="aiab-slats aiab-slats--products">
  <li>
    <article class="aiab-slat-item">
      <figure class="aiab-slat-image">
        <img src="product.jpg" alt="Product name">
      </figure>
      <div class="aiab-slat-content">
        <h3>Product Name</h3>
        <p>Product description with relevant details.</p>
        <div class="aiab-slat-meta">
          <span class="aiab-price">$99.99</span>
        </div>
      </div>
      <div class="aiab-slat-actions">
        <button class="aiab-btn aiab-btn--primary">Add to Cart</button>
      </div>
    </article>
  </li>
</ul>
