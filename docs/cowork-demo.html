Step 2 — Craft Offers

What it does: Uses the edited brainstorm output to generate 3 distinct offers, each with 5 delivery vehicles framed as their own sub-offers. Applies Hormozi's value equation: Dream Outcome × Perceived Likelihood of Achievement / Time Delay × Effort and Sacrifice.

Prompt logic: Passes the full intake + edited Step 1 output into the Craft Offers prompt. Marco runs as harmoziGPT persona internally.

Output:

  • 3 named offers, each following the format: "[Framework Name]: How to [YAY] without [BOO] even if [GREATEST OBSTACLE]"
  • 5 delivery vehicles per offer, framed as their own offers
  • Formatted in markdown with H1/H2 hierarchy

User intervention: Marco presents all 3 offers and asks the user to:

  1. Rate each offer 1–3 (keep, maybe, cut)
  2. Optionally rename any offer
  3. Flag any delivery vehicle that's operationally impossible

Only the kept offers advance to Step 3. If user keeps all 3, all 3 go forward.
